# Security

`react-native-scroll-interop` is a client-side React Native/Android library and does not provide a network service or authentication layer.

For security-sensitive reports that should not be public, use GitHub's private vulnerability reporting for this repository when available. Do not include secrets, tokens, private application data, or proprietary reproduction material in a public issue.

For ordinary crashes, build failures, scroll lifecycle bugs, or compatibility regressions, use the public issue templates instead.

Supported security fixes track the currently published release line. During the `0.1.x-alpha` phase, users should expect to update to the newest alpha rather than receive long-lived patch branches for older prereleases.
